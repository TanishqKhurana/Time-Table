# Time-Table
Smart Time table using Arduino
This device uses RTC sensor to display current time and can display what class is going on at the moment with the data we have inserted it. You can also use it to set your reminders and use it as a handy desk device that can remind you of your important meetings, tasks, etc
Components used- Arduino Uno
               -DS3231 Real Time Clock
               -16x2 LCD Display
               -Arudino IDE
